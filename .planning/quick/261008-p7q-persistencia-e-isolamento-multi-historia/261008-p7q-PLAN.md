# Quick Task Plan: 261008-p7q - Persistência & Isolamento Multi-História (Fase 4)

## Objective
Garantir persistência robusta, agnóstica e isolada para múltiplas campanhas, sistemas e histórias no banco de dados local (Dexie IndexedDB), permitindo adicionar novos modos de jogo/lore sem vazamento de dados entre salas ou quebras de compatibilidade.

## Root Causes & Identified Gaps
1. **Falta de indexação de campanha em Monstros Customizados**: `customMonsters` no Dexie não possui índices para `campaignId` ou `system`, impossibilitando isolamento de bestiários por campanha ou sistema de regras.
2. **Ausência de exclusão em cascata**: Deletar uma aventura em `AdventureContext.tsx` só deletava mapas e a própria campanha, deixando personagens, cenas, assets e monstros customizados órfãos no IndexedDB.
3. **Fragilidade de sumários em sistemas alternativos**: Se uma ficha pertencer a outro sistema (sem `race`, `class` ou `level`), `CharacterRepository.listAll` poderia expor campos `undefined` ou quebrar componentes que esperam strings válidas.
4. **Isolamento de Bestiário (`MonsterRepository.ts`)**: `getAll()` e `getCustomMonsters()` não aceitam filtros opcionais por campanha ou sistema, misturando monstros de diferentes campanhas/sistemas.

## Proposed Changes
1. **`src/db/RPGDatabase.ts`**:
   - Atualizar interface `Campaign` com `system?: string` e `description?: string`.
   - Atualizar interface `Monster` em `monsterTypes.ts` com `campaignId?: string` e `system?: string`.
   - Adicionar versão 3 do schema no Dexie:
     - `campaigns: 'id, name, system, createdAt, updatedAt'`
     - `customMonsters: 'id, name, category, source, cr, campaignId, system'`
2. **`src/features/adventure/AdventureContext.tsx`**:
   - Adicionar suporte a parâmetro opcional `system?: string` em `createAdventure(name, system)`.
   - Implementar exclusão atômica em cascata em `deleteAdventure(id)` para remover mapas, cenas, assets, personagens e monstros associados à campanha.
3. **`src/features/character/characterRepository.ts` & `characterTypes.ts`**:
   - Adicionar `system?: string` no modelo de Personagem.
   - Fornecer fallbacks seguros (`race || ''`, `class || ''`, `level ?? 1`) em `listAll`.
4. **`src/features/monsters/MonsterRepository.ts`**:
   - Permitir filtro opcional em `getCustomMonsters(campaignId?: string)`.
   - Permitir filtro opcional em `getAll(filter?: { source?: string; campaignId?: string; system?: string })`.
5. **Atualizar `test-storage-dexie.mjs`**:
   - Testar migração de schema Dexie v3.
   - Testar isolamento estrito entre campanhas para personagens e monstros customizados.
   - Testar exclusão em cascata completa.
   - Testar resiliência com fichas sem atributos do 5e.
   - Executar suíte completa (`npm test`).

## Success Criteria
- 100% dos testes passam em `npm run test:storage` e `npm test`.
- Compilação limpa em `npx tsc -b`.
- Build de produção bem sucedido em `npm run build`.
